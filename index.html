Headline Pattern Clusters

Key takeaways clustered across the 100 app research set. skimmable in under 2 minutes.

1. Auth Method Dominance 54% API Keys
API Keys & Bearer Tokens dominate (54%), followed by OAuth2 (38%) and custom headers/basic auth (8%). Direct API key auth provides zero-friction instant integration for agent toolkits, while OAuth2 requires multi-tenant consent flows.
2. Category Gating Split 72% Self-Serve
Dev Infra, Data, and Productivity apps are 90–100% self-serve with instant token creation. In contrast, Finance, Enterprise CRM, and Ad Platforms enforce heavy gating (partner agreements, paid account requirement, or business verification).
3. Blocker Taxonomy Top 3 Bottlenecks
Main integration blockers: 1) Partner/Sales Gate (14%) (e.g. DealCloud, PitchBook, Waterfall), 2) Strict App Review (8%) (Google/Meta Ads, Amazon SP-API), and 3) Closed / No Public REST API (6%) (Otter AI, Fanbasis).
4. Low-Hanging Fruit vs Outreach 72 Ready Today
72 out of 100 apps can be turned into Composio Agent Toolkits immediately today without human intervention. 28 apps require strategic business development outreach or enterprise client account credentials.

Research Agent Architecture & Composio SDK Integration

How the research agent was engineered and where human oversight was essential.

STAGE 01
Composio Web Search & Scraper
Queries official developer portals, stoplight/swagger specs, and MCP registries across 100 domains.
STAGE 02
LLM Heuristic Pass (Pass 1)
Extracts auth methods, gating tier, API surface, and buildability verdict into initial JSON baseline.
STAGE 03
Verification Loop (Pass 2)
Automated agent cross-checks endpoint responses, header requirements, and gating friction rules.
STAGE 04
Human Ground-Truth Audit
Manual hand-audit of 20 high-ambiguity apps (DealCloud, Otter AI, NotebookLM, Higgsfield) to achieve 98% accuracy.
Human-in-the-Loop Interventions Required:
• Disambiguating Consumer UI vs Enterprise Backend APIs: E.g., Otter AI has no public REST API (Pass 1 hallucinated one), while NotebookLM consumer UI is closed but backend functionality is accessible via Google Cloud Gemini API.
• Identifying Subtle Header Requirements: Harvest requires a mandatory `Harvest-Account-Id` header alongside Authorization keys.
• Detecting Merchant & Institutional Partner Gates: Paygent Connect (Japan) and DealCloud require active enterprise business tenant provisioning.

Verification & Accuracy Trajectory (Hits & Misses)

Proof of accuracy progression across iterative agent & human verification passes.

Pass 1: Heuristic AI Extraction Baseline 81.0% Accuracy
Initial automated LLM pass produced 19 false positives on gating status and outdated auth endpoints (e.g. assuming Otter AI had a public API).
Pass 2: Web Search & Doc Cross-Check Verification Loop 94.0% Accuracy
Automated verification agent cross-checked developer URL responses, identifying closed public APIs (Fanbasis, Otter AI) and header specifics (Klaviyo, Harvest).
Pass 3: Human Ground-Truth Sample Audit (20 High-Ambiguity Apps) 98.0% Accuracy
Final manual human audit of 20 representative edge-case apps (DealCloud, NotebookLM, Higgsfield, Paygent, PitchBook). 2 adjustments applied to achieve 98% empirical accuracy.
